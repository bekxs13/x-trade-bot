Editing access

To add or remove accounts from this page, it needs a GitHub token that can edit this one repo. You only do this once per phone or browser, and it's stored only on this device.

  1. Open GitHub → new fine-grained token.
  2. Name it anything, pick the longest expiration, and under Repository access choose Only select repositories → .
  3. Under Permissions, add Contents and switch it from Read-only to Read and write (it starts as Read-only).
  4. Generate it, copy it, and paste it here.

No token? You can still edit accounts.txt on GitHub directly.
