Add an account

The bot picks it up on its next check. It reads their last 10 posts once to fill in the board and feed (no pings for those), then pings you on new posts.

Watching

Notes help the bot read an account: slang, how they tag positions, running jokes, what they usually trade. They're sent with every post from that account.

What the bot has learned

Each correction you send becomes a short lesson the bot reads before every post. If a lesson is wrong, tap Forget.

Editing access

To add, remove, or write notes from this page, it needs a GitHub token that can edit this one repo. You do this once per phone or browser, and the token is stored only on this device.

  1. Open GitHub → new fine-grained token.
  2. Name it anything, pick the longest expiration, and under Repository access choose Only select repositories → .
  3. Under Permissions, click + Add permissions, pick Contents and Actions, and set both to Read and write (they start as Read-only). Contents lets this page edit accounts and notes; Actions lets Check now start the bot. Metadata is added automatically.
  4. Generate it, copy it, and paste it here.

No token? You can still edit accounts.txt and the notes folder on GitHub.

Teach the bot

Tell it what it missed or got wrong. It turns this into a lesson it reads before every post, and if you link a post it reads that post again and fixes the board.
